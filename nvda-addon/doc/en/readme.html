A11y Task Recorder

Records NVDA gestures paired with accessibility object metadata, groups speech fragments by element, and records speech completion or interruption times while a local session is active in a supported browser.

Commands

NVDA+Control+Shift+M
Mark the current point as a usability problem.
NVDA+Control+Shift+R
Report recording status using tones.

Printable input characters and audio are not stored. Accessibility context can include accessible name, role, state, and IA2UniqueID.
