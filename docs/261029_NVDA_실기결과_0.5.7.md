## 재현 순서

- **D-2 CJ 쿠키 대화상자**: T01 → 과업 4(또는 5·6) 지시문 → 과업 시작. 브라우즈 모드에서 바로 "쿠키 사용 대화상자"가 읽히고, H는 "다음 제목 없음"입니다. "동의"를 눌러야 본문으로 갑니다. 다음 CJ 과업에서 다시 뜹니다.
  - 정할 것: 사이트 준비 단계에서 동의 쿠키를 미리 넣거나 사본에서 대화상자를 빼는 방법, 또는 이 대화상자를 과업의 일부로 두고 지시문이나 진행 안내에 적는 방법이 있습니다. 과업마다 쿠키가 초기화되는 것으로 보입니다.
- **D-5 무음 대기**: 재현 조건은 정하지 못했습니다(첫 준비 18회 중 2회: T01 과업 11은 LO 첫 과업, T03 과업 1은 테스터를 바꾼 뒤 첫 과업. 같은 조건인 T01 과업 7, T03 과업 3은 정상).
  - 저장(또는 본 과업으로 가기) → 지시문이 읽힘 → Tab, Enter(과업 시작). 그 뒤 약 38초 동안 아무 말이 없습니다 → "사이트를 다시 여는 중입니다." → 약 11초 뒤 과업 시작.
  - 코드상 `start()`가 `view.siteLoading`을 조용히 기다립니다(study.js 582~585행). 첫 준비 안의 10초 다시 열기(516~521행)로는 회복되지 않았고, `start()`의 `reloadSite()`가 회복시켰습니다. 기다리는 동안 "사이트를 준비하고 있습니다. 잠시 기다려 주세요." 같은 알림을 한 번 주거나, 첫 준비 안의 다시 열기를 `reloadSite()`와 같은 방식으로 하면 대기가 짧아질 수 있습니다.
- **A-5 Escape 두 번**: 저장한 과업 다시 하기 → (초점이 선택 상자) → Escape → 아무 말 없음 → Escape → "저장한 과업 다시 하기 버튼".
