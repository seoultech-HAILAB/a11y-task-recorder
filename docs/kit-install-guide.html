평가 키트 설치 안내

NVDA로 읽도록 만든 안내입니다. H 키를 누르면 다음 단계 제목으로, 아래 화살표를 누르면 한 줄씩 읽습니다. 단계마다 누를 키, 들리는 말, 안 될 때를 적었습니다.

모든 단계는 키보드로 합니다. 설치는 10분 안팎이 걸립니다.

준비물

  • Windows 10 또는 Windows 11 컴퓨터(64비트)
  • NVDA 2024.1 이상. 켜 둔 채로 시작합니다.
  • 이어폰이나 스피커
  • 연구진이 메일이나 드라이브 링크로 보낸 키트 ZIP 파일. 파일 이름은 A11yTaskRecorder로 시작하고, 크기는 약 200MB입니다.
  • 연구진에게 받은 테스터 번호(예: 1)

1단계. ZIP 파일 내려받기

  1. 연구진이 보낸 메일이나 드라이브 링크에서 키트 ZIP 파일을 내려받습니다.
  2. 크기가 커서 몇 분 걸릴 수 있습니다. Chrome과 Edge는 내려받은 파일을 다운로드 폴더에 저장합니다.

2단계. 다운로드 폴더 열기

  1. Windows+R을 누릅니다. "실행 대화상자"와 "열기 콤보상자"가 들립니다.
  2. 영어 입력 상태에서 shell:downloads를 입력하고 Enter를 누릅니다.
  3. "다운로드 - 파일 탐색기"가 들리고, 가장 최근에 받은 파일에 초점이 갑니다. "A11yTaskRecorder"로 시작하는 이름이 들리면 그 파일입니다. 아니면 아래 화살표로 찾습니다. 파일 이름 끝의 .zip은 읽히지 않을 수 있습니다.

안 될 때: 파일 탐색기(Windows+E)를 열고 Alt+D로 주소 표시줄에 가서 shell:downloads를 입력하고 Enter를 누릅니다.

3단계. 압축 풀기

  1. ZIP 파일에 초점이 있는 채로 Shift+F10(또는 응용 프로그램 키)을 누릅니다. "팝업 윈도우"가 들립니다.
  2. Windows 11에서는 메뉴 맨 위에서 잘라내기, 복사, 이름 바꾸기, 공유, 삭제 5개가 먼저 읽힙니다. 아래 화살표를 계속 눌러 "압축 풀기"가 들리면 Enter를 누릅니다. 메뉴 13개 중 6번째쯤입니다. Windows 10에서는 이름이 "모두 압축 풀기"입니다.
  3. "압축(Zip) 폴더 풀기" 창이 열리고 "압축을 풀어서 다음 폴더에 저장 입력란"이 들립니다. 위치는 바꾸지 말고 Enter를 누릅니다.
  4. "14% 완료"처럼 진행률이 읽히고, 1~2분 뒤 압축이 풀린 폴더가 새 창으로 열립니다.

안 될 때: 메뉴에 "압축 풀기"나 "모두 압축 풀기"가 없으면 다른 압축 프로그램이 ZIP을 맡고 있는 경우입니다. 그 프로그램으로 풀어도 되고, 어려우면 연구진에게 알려 주세요.

4단계. 키트 폴더로 들어가기

  1. 새 창에서 "파일 탐색기"와 A11yTaskRecorder로 시작하는 폴더 이름, "선택 안 됨 1개 중 1번째"가 들립니다.
  2. Space를 눌러 "선택됨"이 들리면 Enter를 눌러 들어갑니다. 선택하지 않고 Enter만 누르면 들어가지지 않습니다.
  3. 안에는 항목 5개가 있습니다: 애드온 파일(a11yTaskRecorder), 설치안내, 평가시작, app 폴더, _연구진용 폴더. 평가시작 말고는 열지 않습니다.

5단계. 평가시작 실행

  1. 위아래 화살표로 5개 항목 중 "평가시작"을 찾아 Enter를 누릅니다. 항목 순서는 컴퓨터마다 다를 수 있습니다.
  2. "파일 열기 - 보안 경고 대화상자, 게시자를 확인하지 못했습니다. 그래도 이 소프트웨어를 실행하시겠습니까?"가 들리고, 초점은 "취소 버튼"에 있습니다. 연구진에게 받은 키트일 때만 Shift+Tab으로 "실행 버튼"으로 가서 Enter를 누릅니다(Alt+R도 됩니다). 이 창은 평가시작을 실행할 때마다 나옵니다.
  3. 드물게 "Windows의 PC 보호" 창이 나오면 Tab으로 "추가 정보"로 가서 Enter, 다시 Tab으로 "실행" 버튼으로 가서 Enter를 누릅니다.

6단계. 20초쯤 기다리기

  1. 처음 실행할 때는 기록용 NVDA 애드온을 설치하느라 NVDA가 한 번 다시 시작됩니다. 잠깐 말이 끊겨도 그대로 기다립니다. 두 번째부터는 다시 시작하지 않습니다.
  2. "A11y Task Recorder 서버" 창이 최소화된 채로 열립니다. 이 창은 따로 열거나 닫지 않아도 됩니다.
  3. 기록 화면이 열리고 "테스터 번호 입력란"이 들립니다.

안 될 때: 30초가 지나도 "테스터 번호"가 들리지 않으면 Alt+Tab으로 "A11y Task Recorder" 창을 찾아 봅니다. 창이 없으면 5단계부터 다시 합니다.

7단계. 테스터 번호 넣고 시작

  1. 받은 테스터 번호를 숫자로 입력하고 Enter를 누릅니다. 1번이면 1만 입력하면 됩니다.
  2. 연습 안내가 바로 읽힙니다. 그다음은 기록 화면이 읽어 주는 안내를 따라 합니다.

과업에서 쓰는 키는 두 개입니다. 연습에서 직접 써 봅니다.

  • NVDA+Ctrl+H: 지시문 다시 듣기
  • NVDA+Ctrl+E: 과업 끝내기. 답을 찾았거나 더 할 수 없으면 그 자리에서 누릅니다.

모든 과업을 마친 뒤

  1. "모든 과업을 마쳤습니다"가 들리면 연구진에게 알립니다.
  2. 연구진이 결과 파일을 보내 달라고 하면 Tab으로 "결과 패키지 만들기" 버튼으로 가서 Enter를 누릅니다. "결과 - 파일 탐색기"가 열리고 결과패키지로 시작하는 ZIP 파일에 초점이 갑니다. 이 파일을 메일에 첨부해 보냅니다.
  3. Alt+F4를 누르면 결과 폴더 창이 닫히고 기록 화면으로 돌아옵니다. 한 번 더 Alt+F4를 누르면 기록 화면이 닫힙니다.
  4. 서버 창은 기록 화면을 닫고 3분 뒤 저절로 닫힙니다.

중간에 멈췄을 때

  • 컴퓨터를 껐거나 기록 화면을 닫았으면 4단계 폴더에서 평가시작을 다시 실행합니다. 테스터 번호를 다시 묻지 않고, 저장한 다음 과업의 지시문부터 이어집니다.
  • 쉬고 싶으면 지시문이 읽힌 화면에서 쉬었다가 "과업 시작"을 누르면 됩니다.

안 될 때

"NVDA가 연결되지 않아 과업을 시작하지 않았습니다"가 들려요

기록 화면을 Alt+F4로 닫고 평가시작을 다시 실행합니다. 그래도 같으면 연구진에게 알려 주세요.

"사이트에 접속할 수 없습니다"가 들려요

"과업 시작"을 다시 누르면 사이트를 다시 엽니다. 계속되면 인터넷 연결을 확인하고 연구진에게 알려 주세요.

단축키를 누르면 낮은 음만 나요

지금은 그 키를 쓸 수 없는 단계입니다. 예를 들어 과업을 시작하기 전에는 끝내기를 쓸 수 없습니다.

테스터 번호를 잘못 넣었어요

지시문 화면에서 Tab으로 "테스터 번호 바꾸기" 버튼으로 가서 다시 입력합니다. 과업 중에는 바꿀 수 없습니다.

저장한 과업을 다시 해야 해요

기술 문제나 방해로 제대로 못 했으면 지시문 화면의 "저장한 과업 다시 하기"로 과업과 이유를 고릅니다. 앞 기록은 지우지 않습니다.

NVDA가 설치되어 있지 않아요

NVDA 내려받기 페이지에서 설치한 뒤 5단계부터 합니다.

기록되는 것

  • 과업을 시작한 순간부터 끝낼 때까지만 기록합니다.
  • 누른 키와 입력한 글자, 그때 초점이 있던 요소, NVDA가 읽어 준 문장, 방문한 페이지 주소와 제목, 고른 결과와 적은 답입니다. 과업에 넣는 값은 연구진이 준 가상 값입니다.
  • 목소리 녹음과 화면 녹화는 하지 않습니다.
  • 기록은 이 컴퓨터의 키트 폴더 안에만 저장되고, 결과 패키지 ZIP으로 연구진에게 전달합니다.
