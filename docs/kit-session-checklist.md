# 과업 기록기 진행 안내

처음부터 끝까지 혼자 진행할 수 있습니다. 자세한 설치 방법은 같은 폴더의 `설치안내.html`에 있습니다.

## 한눈에

1. 켜기: `평가시작.bat` 실행
2. 테스터: 받은 테스터 번호를 입력하고 시작
3. 연습: 저절로 열립니다. 단축키를 여기서 익힙니다
4. 과업: 지시문 듣기, 과업 시작, 수행, 끝내기, 결과 저장을 반복
5. 결과: 결과 패키지 ZIP을 연구진에게 보내기

준비 약 3분, 마무리 약 2분이면 됩니다.

## 단축키

단축키는 연습에서 한 번 안내하고, 본 과업에서는 다시 말하지 않습니다.

- NVDA, Ctrl, E: 과업 끝내기. 가장 중요합니다.
- NVDA, Ctrl, H: 지시문 다시 듣기. 지시문만 읽습니다.
- Alt, 왼쪽 화살표: 사이트 안에서 이전 페이지. 과업 시작 화면까지만 갑니다.
- Alt, Home: 과업 처음 화면.

NVDA 키는 Insert 또는 CapsLock입니다. 과업 중에는 초점이 사이트 밖으로 나가지 않고, NVDA, Ctrl, E를 눌러야 결과 화면으로 넘어갑니다.

## 1. 켜기와 테스터 번호

0. 처음 한 번: NVDA 메뉴 > 설정 > 일반에서 "NVDA 시작 시 업데이트 자동 확인"을 끕니다. 과업 중에 업데이트 창이 뜨면 초점을 가져갑니다(10/28 점검).
1. `평가시작.bat`을 더블클릭합니다. 검은 서버 창은 끝날 때까지 그대로 둡니다. 닫으면 기록이 멈춥니다.
2. 기록 화면이 주소창 없는 창으로 열립니다. 흰 화면 그대로이면 8초쯤 뒤 저절로 다시 열립니다. 그래도 비어 있으면 F5를 누릅니다.
3. 받은 테스터 번호를 입력하고 "시작"을 누릅니다. T01은 "1"이나 "01"로 넣어도 됩니다.
4. 처음이면 연습 안내가 바로 읽힙니다.

## 2. 연습

- 연습 안내를 듣고 NVDA, Ctrl, H를 한 번 눌러 본 뒤 "과업 시작"을 누릅니다.
- 연습 화면에서 "재료 보기"를 누르고, 재료를 확인했으면 NVDA, Ctrl, E로 끝냅니다.
- 결과에서 성공 또는 실패를 고르고 답을 적어 저장합니다.
- 끝나면 두 단축키를 써 봤는지 알려 줍니다. "본 과업으로 가기" 또는 "연습 다시 하기"를 고릅니다.
- 지시문 화면, 제한 시간 안내 화면, 모든 과업을 마친 화면에서 "연습 다시 하기"로 언제든 다시 연습할 수 있습니다. 과업 중과 결과 입력 중에는 열지 않습니다(저장하면 바로 다음 지시문 화면이 나옵니다).

## 3. 과업

- 과업 화면이 나오면 지시문만 읽힙니다. 아래 "과업 시작"을 누르면 사이트가 열리고 기록이 시작됩니다.
- 답을 찾았거나 더 할 수 없으면 그 자리에서 NVDA, Ctrl, E를 누릅니다. 막혀도 끝냅니다. 막힌 것도 중요한 기록입니다.
- 결과 화면에서 성공 또는 실패를 고르고 답을 적어 "저장"합니다. 저장하면 바로 다음 과업의 지시문이 읽힙니다.
- 한 과업은 최대 10분입니다. 시간이 되면 저절로 끝나고 "다음 과업" 버튼이 나옵니다.
- 쉬고 싶으면 지시문 화면에서 쉬었다가 "과업 시작"을 누르면 됩니다.

## 4. 잘못했을 때 되돌리기

저장된 기록은 지워지지 않습니다. 취소한 시도는 분석에서만 빠집니다.

- 끝내기를 잘못 눌렀다: 결과 화면의 "과업으로 돌아가기". 끝낸 자리에서 이어서 합니다.
- 과업을 처음부터 다시 하고 싶다: NVDA, Ctrl, E로 끝낸 뒤 결과 화면의 "과업 처음부터 다시 하기". 확인하면 지시문부터 다시 합니다.
- 테스터 번호를 잘못 넣었다: 지시문 화면 아래 "테스터 번호 바꾸기". 저장된 결과가 있으면 한 번 확인합니다.
- 사이트에서 길을 잃었다: Alt, Home으로 과업 처음 화면.

확인 단계가 열리면 초점은 안전한 쪽(취소)에 있습니다. 저장한 뒤와 제한 시간으로 끝난 과업은 되돌릴 수 없습니다.

## 5. 수행할 때 지킬 것

- 평소 쓰는 탐색 방법(제목, 목록, 검색 등)을 그대로 씁니다.
- 접근성 문제가 보여도 고치거나 우회 방법을 찾기보다 평소처럼 진행합니다.
- 개발자 도구나 다른 창, 다른 브라우저로 같은 과업을 하지 않습니다.

## 6. 이런 문구가 나오면

- "사이트에 접속할 수 없습니다": "과업 시작"을 다시 누르면 사이트를 다시 엽니다. 계속되면 인터넷 연결을 확인하고 연구진에게 알려 주세요. 원인은 기록에 남습니다.
- "기록 프로그램에 연결할 수 없습니다": 검은 서버 창이 켜져 있는지 확인하고, 없으면 `평가시작.bat`을 다시 실행합니다.
- "NVDA가 연결되지 않아 과업을 시작하지 않았습니다": NVDA를 껐다 켠 뒤 F5로 기록 화면을 새로 고칩니다.

## 7. 마무리: 결과 보내기

1. "모든 과업을 마쳤습니다" 화면에서 "결과 패키지 만들기 (담당자용)"를 누릅니다.
2. 열린 "결과" 폴더의 ZIP 파일을 연구진에게 보냅니다. 메일이나 드라이브로만 보내고, 공개된 곳에 올리지 않습니다.
3. 기록 화면을 닫고, 그다음 서버 창을 닫습니다.

중간에 끝내야 하면 지시문 화면의 "테스터 번호 바꾸기"를 누르고, 나타나는 "기록 관리"에서 결과 패키지를 만듭니다.
