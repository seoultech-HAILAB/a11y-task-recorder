# 과업 기록기 진행 안내

처음부터 끝까지 혼자 진행할 수 있습니다. 자세한 설치 방법은 같은 폴더의 `설치안내.html`에 있습니다.

## 한눈에

1. 켜기: `평가시작.bat` 실행
2. 테스터: 테스터 번호 고르고 배정 확인
3. 연습: 연습 시작으로 한 번 해 보기
4. 과업: 지시문 듣기, 과업 시작, 수행, 끝내기, 결과 저장을 반복
5. 결과: 결과 패키지 ZIP을 연구진에게 보내기

준비 약 3분, 마무리 약 2분이면 됩니다.

## 단축키 4개

- NVDA, Ctrl, E: 과업 끝내기. 가장 중요합니다.
- NVDA, Ctrl, H: 지시문 다시 듣기.
- Alt, 왼쪽 화살표: 사이트 안에서 이전 페이지. 과업 시작 화면까지만 갑니다.
- Alt, Home: 과업 처음 화면.

NVDA 키는 Insert 또는 CapsLock입니다. Alt 단축키는 기록 화면을 벗어나지 않습니다.

## 1. 켜기와 테스터 고르기

1. `평가시작.bat`을 더블클릭합니다. 검은 서버 창은 끝날 때까지 그대로 둡니다. 닫으면 기록이 멈춥니다.
2. 기록 화면 위쪽에 "NVDA 연결됨"이 있는지 확인합니다.
3. 받은 테스터 번호를 고르고 "배정 확인"을 누릅니다.
4. "사이트가 준비되었습니다"가 나오면 준비 끝입니다.

## 2. 과업을 끝내는 방법

답을 찾았거나 더 진행할 수 없다고 판단되면, 그 자리에서 NVDA, Ctrl, E를 누릅니다.

- 끝낸 뒤 결과 칸에 마쳤는지와 답을 적고 저장합니다.
- 막혀도 끝냅니다. 막힌 것도 중요한 기록입니다.
- 답을 말로 하거나, 끝내지 않고 다른 페이지를 둘러보지 않습니다.
- 한 과업은 최대 10분입니다. 시간이 되면 결과 입력으로 넘어갑니다.
- 4과업마다 쉬어도 된다는 안내가 나옵니다.

## 3. 잘못했을 때 되돌리기

저장된 기록은 지워지지 않습니다. 취소한 시도는 분석에서만 빠집니다.

- 테스터 번호를 잘못 골랐다: 위쪽 "테스터 번호 바꾸기". 저장된 결과가 있으면 한 번 확인합니다.
- 과업을 잘못 시작했다: 사이트 아래 "과업 다시 시작". 확인하면 지시문부터 다시 합니다.
- 끝내기를 잘못 눌렀다: 결과 화면의 "과업으로 돌아가기". 끝낸 자리에서 이어서 합니다.
- 처음부터 다시 하고 싶다: 결과 화면의 "처음부터 다시 하기".
- 사이트에서 길을 잃었다: Alt, Home으로 과업 처음 화면.

확인 단계가 열리면 초점은 안전한 쪽(계속하기, 취소)에 있습니다. 키보드만 쓸 때는 NVDA, Ctrl, E로 끝낸 뒤 결과 화면에서 고르면 됩니다. 제한 시간으로 끝난 과업은 되돌릴 수 없습니다.

## 4. 수행할 때 지킬 것

- 평소 쓰는 탐색 방법(제목, 목록, 검색 등)을 그대로 씁니다.
- 접근성 문제가 보여도 고치거나 우회 방법을 찾기보다 평소처럼 진행합니다.
- 개발자 도구나 다른 탭, 다른 브라우저로 같은 과업을 하지 않습니다.

## 5. 이런 문구가 나오면

- "사이트에 접속할 수 없습니다": 인터넷 연결을 확인합니다. 원인은 기록에 남으니 그대로 연구진에게 알려 주세요.
- "기록 프로그램에 연결할 수 없습니다": 검은 서버 창이 켜져 있는지 확인하고, 없으면 `평가시작.bat`을 다시 실행합니다.
- "NVDA 연결됨"이 보이지 않음: NVDA를 껐다 켠 뒤 기록 화면을 새로 고칩니다.

## 6. 마무리: 결과 보내기

1. "배정된 과업을 모두 마쳤습니다" 화면에서 "결과 패키지 만들기 (담당자용)"를 누릅니다.
2. 열린 "결과" 폴더의 ZIP 파일을 연구진에게 보냅니다. 메일이나 드라이브로만 보내고, 공개된 곳에 올리지 않습니다.
3. 기록 화면을 닫고, 그다음 서버 창을 닫습니다.

중간에 끝내야 하면 `http://127.0.0.1:8765/?change-tester=1`을 열고 "기록 관리"에서 결과 패키지를 만듭니다.
