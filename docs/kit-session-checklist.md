# 세션 당일 진행 안내 (담당자용)

자세한 설명은 같은 폴더의 `설치안내.html`에 있습니다. 이 문서는 세션마다 따라 하는 순서만 적었습니다.

## 세션 전 (약 3분)

1. `평가시작.bat`을 더블클릭합니다.
2. 검은색 서버 창과 기록 화면이 열리면, 서버 창은 끝날 때까지 그대로 둡니다.
3. 기록 화면 위쪽에 **NVDA 연결됨**이 보이는지 확인합니다.
4. 참가자의 **테스터 번호**를 고르고 **배정 확인**을 누릅니다.
5. "사이트가 준비되었습니다"가 나오면 참가자에게 자리를 넘깁니다. "사이트에 접속할 수 없습니다"가 나오면 인터넷 연결을 확인하고 연구진에게 알려 주세요.

## 참가자에게 할 말 (그대로 읽어도 됩니다)

> "화면 안내를 따라 혼자 진행하시면 됩니다. 처음에는 연습 시작으로 한 번 연습해 보세요.
> 지시문을 듣고 과업 시작 버튼을 누르면 사이트가 열립니다. 다 하셨거나 더 진행할 수 없으면
> NVDA, Ctrl, E를 함께 누르세요. 그다음 마쳤는지와 답을 적어 저장하고 다음 과업으로 넘어가시면 됩니다.
> 하다가 지시문이 기억나지 않으면 NVDA, Ctrl, H를 누르세요. 기계에 문제가 생겼을 때만 저를 불러 주세요."

## 세션 중

- 과업 내용이나 답은 알려 주지 않습니다. 기술 문제(소리가 안 남, 화면 멈춤)만 돕습니다.
- 4개 과업마다 쉬어도 된다는 안내가 나옵니다. 쉬는 시간은 참가자가 정합니다.

## 세션 후 (약 2분)

1. "배정된 과업을 모두 마쳤습니다" 화면에서 **결과 패키지 만들기 (담당자용)**를 누릅니다.
2. 열린 **결과** 폴더의 ZIP 파일을 연구진에게 보냅니다. 과업 기록은 연구 서버로도 자동 전송되지만 ZIP은 꼭 보내 주세요.
3. 기록 화면과 서버 창을 닫습니다.

중간에 끝내야 하면 `http://127.0.0.1:8765/?change-tester=1`을 열고 **기록 관리**에서 결과 패키지를 만듭니다.
