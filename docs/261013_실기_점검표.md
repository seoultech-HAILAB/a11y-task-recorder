# 0.4.0 한 창 기록기 실기 점검표 (Windows 노트북 + NVDA)

작성 2026-10-12. 10/15 go/no-go 판단용. **모든 항목은 실제 NVDA에서 사람이 확인한다.** Linux Playwright(`scripts/verify_single_window.cjs`)가 통과한 항목도 NVDA 동작은 미확인이므로 여기서 다시 본다. 환경: SNC 연구원 노트북 1대, 스피커 출력, 평가원이 돌아가며 사용.

## 서버 전송 경로에서 실기로만 확인되는 것

- 노트북의 회사 네트워크에서 사본 서버의 `/upload/session`에 HTTPS POST가 나가는가(프록시·방화벽). 사이트 사본이 열리면 같은 경로라 대개 같이 열린다.
- 임베디드 Python(키트 `app\python`)의 TLS 인증서 검증: Windows 인증서 저장소를 쓰므로 Let's Encrypt 체인이 검증되어야 한다. 실패하면 `last_error`가 `URLError`로 남고 전송은 대기열에 남는다(세션 영향 없음).
- 30MB 상한: 10분 과업의 세션 JSON은 보통 1~5MB다. 상한에 걸리면 `too_large`로 남고 ZIP으로만 전달.
- 재시도 주기 120초가 세션 진행과 겹칠 때 CPU·소리 영향이 없는지.
